怎么发布一篇新周报？（3 步）

本站是纯静态站点，周报以 Markdown 文件形式存在仓库里，推送到 GitHub 后自动生效。

  1. 在 weekly/posts/ 下新建一个文件，例如 2026-09-19.md。
  2. 复制 weekly/posts/_TEMPLATE.md 的格式填写标题、日期、标签和正文。
  3. 在项目根目录运行 npm run weekly，然后提交推送即可。

忘记运行脚本也没关系 —— 推送后 GitHub Actions 会自动重建一次。 图片放在 assets/img/，正文里用 ![说明](assets/img/xxx.png) 引用。
