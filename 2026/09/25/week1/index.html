5.http协议

1.http协议是浏览器和服务器之间交互的协议，是在应用层的协议，基于TCP连接方式
2.路径为http: // IP地址或域名：端口（一般为80）/一堆参数，若没有，则为根路径，若有，一般是子路径
3.http协议包括请求协议和响应协议，都有三部分，请求行（响应行），请求头（响应头），请求体（响应体，我的理解是返还的网页）
4.get只读取，不改变，提交的请求一般不放在请求体中，放在url之后，以？分割url和请求参数，请求参数以&连接；post触发处理。get具有幂等性，可缓存；post是不幂等的，默认不缓存。两者都是明文，不加密，没什么安全性，要依靠HTTPS保密
5.常见请求头（由键值对构成）：host域名，connection连接方式，user-agent客户端信息，accept-charset声明客户端接收的字符集，referer记录请求来源的完整url（我认为就是上一个页面地址）
6.接口鉴权：
鉴权
cookie 服务器向客户端发送的小段文本数据，客户端自动携带它，让服务器认出
jwt 将用户信息编码进令牌，拦截器自动在请求头书写token
session 用户登录后服务器保存对话数据并生成对应session id，以cookie形式发送客户端，后续以session id查找对话数据，对用户进行认证
7.状态码
状态码
200 成功
302 资源迁移但请求仍使用原url
403 权限不足
500 服务器内部错误
502 网关或代理服务器无响应
504 网关或代理服务器响应超时

7.devtools

面板 核心作用
Elements 元素 查看/实时编辑页面的 HTML 结构与 CSS 样式
Console 控制台 实时运行 JavaScript，查看报错与日志输出
Sources 源代码 查看所有加载的 JS/CSS/HTML 源码,下断点,单步调试,格式化压缩代码
Network 网络 记录每个请求的 URL、方法、状态码、请求/响应头、请求体、响应体、耗时，可以看 API 接口、参数、Token/Cookie
Memory 内存 堆快照、内存分配时间线，排查内存泄漏
Security 安全 证书信息、TLS 版本、混合内容警告、HSTS 状态
